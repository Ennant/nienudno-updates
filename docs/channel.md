# Kanał aktualizacji Nienudno

Repozytorium służy do anonimowego pobierania podpisanych poprawek launchera. Aktualizacje nie wymagają konta GitHub ani włączonego komputera autora.

Paczki są adresowane skrótem SHA-256. Klient sprawdza podpis RSA manifestu i skróty wszystkich plików przed aktywacją. Dane dzieci, zapisy światów oraz prywatne klucze publikatora pozostają poza repozytorium.

Kanał produkcyjny zostanie udostępniony po sprawdzeniu pobrania i aktualizacji istniejących instalacji. Samo istnienie tej dokumentacji nie oznacza gotowego wydania.
